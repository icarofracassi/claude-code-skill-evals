How it works
1
Submit via Issue
Open a GitHub Issue using the Submit a Skill template. Paste your skill's Markdown and optional YAML test cases.
2
Label triggers workflow
The label status: eval-pending fires automatically on submission and starts the eval pipeline.
3
Lint runs (free)
A Node.js job checks frontmatter, trigger language, exclusions, and test case YAML. No API key needed.
4
AI evals (optional)
If ANTHROPIC_API_KEY is set, a second job runs LLM-based checks: trigger precision, output quality, scope adherence.
5
Results posted
Both jobs post results as comments on the issue. Reviewer approves, adds status: accepted, and the skill appears here.
Eval checks
#EvalCostWhat it checks
1Structure lintFreeFrontmatter fields (name, description), trigger language, exclusion language, unresolved placeholders, word count, test case YAML shape
2Trigger precisionAPI keyLLM judge: is the description specific enough to route correctly? Would it match unrelated prompts?
3Output qualityAPI keyRuns the skill on each user-provided in-scope test prompt; checks output contains expected keywords
4Scope adherenceAPI keyRuns the skill on out-of-scope prompts; LLM judge verifies the skill declined or redirected correctly

Setup
  1. 1
    Fork or clone the repogithub.com/icarofracassi/claude-code-skill-evals
  2. 2
    Add your Anthropic API key (optional)In Settings → Secrets and variables → Actions, add a secret named ANTHROPIC_API_KEY. Without it, only the free structural lint runs. Get a key →
  3. 3
    Submit a skillOpen an issue using the Submit a Skill template. The label status: eval-pending is applied automatically and triggers the workflow.
  4. 4
    Review and acceptFix any failures, re-trigger with the label, then add status: accepted to publish to this site.
  5. 5
    Run evals locally (optional)pip install anthropic pyyaml, set ANTHROPIC_API_KEY, write your issue body to /tmp/issue_body.txt, then run python scripts/eval_skill.py.
